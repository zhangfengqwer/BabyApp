# 发布与宝宝名片编辑（Android 0.4.28）

0.4.33 PWA 同步日期分组、部分成功重试、视频文件预览、宝宝名片编辑和单媒体长按移除。JPEG 读取 EXIF，MOV/MP4 检查 movie creation headers，1904 零时间过滤；HEIC 等浏览器无法识别的拍摄时间明确回退手选日期，不能把文件修改日期伪装成拍摄日期。减号改为单层深色半透明圆钮，无白色底圈。iOS 的缩略图长按后出现按钮，滑动时取消长按计时；点击按钮仍需确认。网页本次 4 项日期逻辑测试通过，Safari/VoiceOver 真机验证待用户安装检查。

发布页使用分区卡片、系统日期选择器和固定底部发布按钮。主要触控区域至少 48dp，主按钮 56dp，输入和上传状态同时使用文字说明，不仅依赖颜色；支持系统深浅主题。

## 日期归档

- 默认打开“按拍摄日期归档”。JPEG/兼容图片使用 EXIF，视频使用媒体元数据，再尝试系统相册拍摄时间。
- 不同日期分开调用发布 API，每个日期一条时光轴；后端遇到同一天的已有 Moment 时追加媒体。
- 无有效拍摄时间的文件使用手选日期，不把上传日期伪装为拍摄日期。
- 关闭自动归档后，全部媒体使用手选日期。
- 正文和地点用于每个日期，可发布后分别编辑。
- 上传成功的 Asset ID 在本次发布页会话中保留；成功的日期也保留。部分失败时锁定正文和日期，重试继续未成功日期，不重复上传。
- 日期晚于今天时阻止发布并提示。成功后定位到最近一个已发布日期，历史日期未加载时继续分页查找。
- 本版没有持久化后台上传队列；关闭发布页/终止进程后不保证恢复草稿。

## 宝宝名片

从时光轴名片“编辑名片”或“我的 → 编辑宝宝名片”进入。

姓名、昵称、生日、简介和固定头像可编辑；名片优先显示昵称，生日修改后年龄重新计算。更换头像使用 Android Photo Picker，原图交给 Immich，数据库只存 Asset ID。头像上传后若资料保存失败，本次会话重试不重复上传。

`PATCH /babies/:id` 仅 ADMIN 可调用，后端验证姓名、字段长度、UUID 和出生日期。`GET /babies` 返回 `canEdit` 给客户端控制入口。未选择新头像时保留原头像。保存后轻量刷新时间轴宝宝信息，不强制跳顶。

设计依据：Mobile App Design Standards 技能的原生导航、触控尺寸、清晰层级、可读错误和感知性能原则。手机真机视觉、字体放大和 TalkBack 验收仍需安装新包后进行。

2026-09-16 验证：Android `assembleDebug` / `testDebugUnitTest` 成功，10 项测试无失败；后端 19 项测试成功，0.4.28 APK 已发布至更新目录。

0.4.29 修复：本地视频由 Coil VideoFrameDecoder 显示预览，读取的 1904/未来等无效元数据会被过滤并回退手选日期。手选备用日期不会被媒体选择自动覆盖。详情每个媒体下方可独立删除（须确认），`DELETE /moments/:id/assets/:assetId` 仅允许动态管理者调用，只删除业务关联，保留 Immich 原文件、其他媒体及留言。Android 13 项测试和后端 21 项测试通过。
