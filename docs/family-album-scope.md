# 家庭相册实施范围

以用户六张截图和随后确认的功能清单为准。底部仅时光轴 / 我的，发布为悬浮按钮；不再开发独立身高体重模块、商城、会员、AI 和公开分享。

本批源码：
- 移除独立成长 Tab。
- 发布事件日期，按本地日期转换 UTC，允许老照片归档。
- 独立 GET /moments/:id，详情不再依赖列表是否加载该动态。
- PATCH /moments/:id 编辑文字、地点、日期和选择本记录媒体为封面。
- DELETE /moments/:id 仅删除业务动态和关联互动，不调用 Immich 删除媒体。
- 评论分页、发表评论、点赞和取消点赞。
- 查看/编辑权限检查；动态列表落实可见性筛选。
- Android 详情页接入以上接口和删除确认。
- 发布时按 Immich Asset ID 去重：同一照片即使以不同文件名被重复选择，也只关联一次，避免媒体上传成功后动态创建失败。
- 家庭 Wi-Fi 启动时使用本机私有访问密钥自动签发 JWT，不再显示服务器地址、用户名和密码输入；服务器设置仍可在连接失败页和“我的”中修改。

验证：后端编译与 12 项测试通过。用户在本机运行构建脚本后，Android `assembleDebug` / `testDebugUnitTest` 通过（此前 6 项测试，无失败），生成 0.4.4 / versionCode 5 APK。2026-09-05 已构建并部署配套后端及重复媒体兼容修复，保留原数据库和照片；健康检查返回 API、数据库、Immich 均正常，详情接口未登录返回 401。0.4.5 Android 源码尚待本机重新构建和手机验收；健康检查不代表完整功能联调通过。
