# 家庭身份与关系（Android 0.4.30）

首次启动选择家庭成员，此后设备保存用户名并通过家庭访问密钥换取该成员的 JWT。我的页面显示当前关系，可切换身份；切换后重新签发 Token，清空主导航再载入该成员可见数据。

我的 → 家庭成员：管理员可创建成员（用户名/手机号、家庭关系）和修改所有成员关系。用户名不可编辑以保证设备记住的身份稳定；关系支持爸爸、妈妈、爷爷、奶奶、外公、外婆及自定义文字。新成员默认 PARENT，可发布和评论，但不能管理其他人。未开放无家庭关系的任意用户免密码登录。

手机号不是必须，也不申请电话/通讯录权限；系统无法可靠提供号码时可手动输入手机号或英文数字用户名。不发送短信，不将手机号展示在时光轴和评论中。

时光轴与详情以家庭关系显示发布人，同日追加时记录参与发布账号 ID；评论按实际作者的家庭关系显示。关系更改会作用于历史记录。旧记录只知道原作者，无法还原过去共用管理员身份时真实使用手机的家人；按用户要求，现有管理员关系设为爸爸。

成员创建与关系修改 API 都检查 ADMIN 权限，成员查询检查家庭归属。但免密码身份选择仍依赖共享 HOME_ACCESS_KEY，任何持有私人 APK 的人都可以选择管理员，**这不是防冒充认证**。当前策略只适合可信家庭设备，不能用于安全的公网相册；公网开放前必须替换为独立登录或管理员审批的设备授权。

管理接口：GET/POST /babies/:babyId/family，PATCH /babies/:babyId/family/:userId。无删除成员功能，不删除历史作者或评论。

数据库兼容升级脚本 scripts/add-family-contributors.sql 为 Moment 增加 contributorIds，且以原作者回填已有记录；不修改媒体、日期或评论。

UI 使用 Mobile App Design Standards 的原生返回、关系预设、48dp 触控和清晰错误提示；管理员身份在列表中单独标注。真机视觉与TalkBack验收仍需安装新包。
