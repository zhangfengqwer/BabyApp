# 页面与返回逻辑

本次 UI 调整以用户提供的六张图为结构参考，采用暖白、黄色重点色和照片拼图。

- 主导航：时光轴、我的；发布使用悬浮按钮。
- 时光轴：顶部宝宝资料卡，内部切换时光轴 / 日历；悬浮加号打开发布。
- 时光轴列表：事件日期倒序（同一宝宝即成长年龄倒序），以宝宝当日年龄为主标签。
- 拼图卡片点击进入动态详情，不直接打开大图。
- 日历：按月、周日为首列排列；有记录的日期显示缩略图；点击日期直接进入当天最新一条动态详情，不显示中间选择弹框。
- 年龄索引：跳转当前已加载的年龄月份，可加载更早记录。日历也明确标注加载范围，不宣称未加载日期没有记录。
- 动态详情：封面、宝宝当时年龄、日期、全部媒体、正文、地点和作者；点具体照片 / 视频打开查看器。
- 媒体查看器：从详情页点中的媒体开始，加载同一动态的整组照片和视频；未放大时可左右滑动，照片支持双指缩放与放大后拖动，视频使用 Media3 播放。
- 返回：媒体 → 动态详情 → 时光轴 / 日历，保留主页面滚动位置和模式。
- 发布成功：关闭发布页并刷新主列表。
- 我的：发布入口、服务器设置和真实版本号。

详情页已接入评论 / 点赞、编辑、选择封面和仅删除动态的接口，配套后端已部署，待手机验收；不展示会员、AI、虚假通知数字或不能工作的分享按钮。独立身高体重业务已移出本版范围。

验证状态：0.4.4 已通过本机 APK 构建和 6 项 Android 单元测试；手机视觉与返回路径尚待验收，不能用编译通过代替实际交互验收。
